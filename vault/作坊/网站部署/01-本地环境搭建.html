网页笔记四步工作流

页面大纲

01 本地环境搭建 ​

本地环境搭建是在你自己的电脑上安装运行本知识库所需的工具，包括 Node.js 和 pnpm。完成后你可以在本地预览博客的渲染效果。

一、获取源代码 ​

首先，克隆或下载本仓库到本地：

shell
git clone https://github.com/star-nebula/knowledge.git

克隆完成后，进入项目目录：

shell
cd knowledge

二、安装依赖工具 ​

本知识库使用以下工具链：

工具版本要求用途
Node.js22.x 或更高JavaScript 运行环境
pnpm8.x 或更高包管理器

Windows 环境 ​

推荐使用 scoop（Windows 上的包管理器）：

打开 PowerShell，依次执行：

powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
powershell
Invoke-RestMethod -Uri https://get.scoop.sh | Invoke-Expression

安装好 scoop 后，通过以下命令安装 Node.js 和 Python：

shell
scoop install nodejs
scoop install python

为什么需要 Python？ 本项目在构建时使用到 sharp 库处理图片，而 sharp 在底层依赖 Python。如果跳过 Python 的安装，构建步骤可能会报错。

macOS 环境 ​

推荐使用 Homebrew 安装：

shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
shell
brew install node

Linux 环境（Ubuntu/Debian） ​

shell
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs

验证 Node.js 安装 ​

安装完成后，验证 Node.js 是否安装成功：

shell
node --version

如果你看到了类似 v22.x.x 的版本号，说明安装成功。

三、安装 pnpm ​

pnpm 是本项目使用的包管理器。通过 Node.js 内置的 corepack 来激活：

shell
corepack enable
shell
corepack prepare pnpm@latest --activate

首次安装完成后执行：

shell
pnpm setup

然后关闭当前终端窗口，重新打开一个新窗口，使配置生效。

验证 pnpm 安装 ​

shell
pnpm --version

如果能看到版本号，则说明安装成功。

四、安装项目依赖 ​

进入项目目录后，执行以下命令安装所有依赖：

shell
pnpm install

这个命令会读取 package.json 中声明的依赖列表，并将它们下载到本地的 node_modules 目录中。

💡 提示：如果你的网络环境访问 npm 源较慢，可以配置 pnpm 使用国内镜像：

shell
pnpm config set registry https://registry.npmmirror.com

五、环境搭建完成清单 ​

步骤验证命令预期输出
✅ Git 已安装git --version显示 git 版本号
✅ Node.js 已安装node --versionv22.x.x 或更高
✅ pnpm 已安装pnpm --version显示版本号
✅ 项目依赖已安装pnpm install 完成后无报错看到进度条完成

完成以上步骤后，你就可以继续阅读 本地预览，学习如何在本地运行和预览博客了！
