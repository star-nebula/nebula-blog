# 七种笔记法其实是一套流水线的七个工位

关于笔记方法的文章大多是并列式的：闪念笔记法、文献笔记法、永久笔记法、原子笔记法、MOC、常青笔记、卡片盒笔记——七种，挑一个适合你的。

这个框架是错的。

它们不是七个可选项，是**同一条流水线上的七个工位**。你不需要选，你需要的是让原料依次经过它们。任何一环缺失，最后产出的就不是知识，只是一批写得很整齐的文档。

## 一、七个工位分别在干什么

先看清分工，再谈流程。

| 工位 | 职责 | 一句话判断 |
|---|---|---|
| 闪念笔记 | 接住念头，不做整理 | 十秒内能记完，否则不算闪念 |
| 文献笔记 | 摘录外部信息，标明来源 | 里面应该全是别人的话 |
| 永久笔记 | 用自己的话重写，形成可复用的观点 | 如果删掉原文还看得懂，才算合格 |
| 原子笔记 | 一篇只讲一件事 | 标题写不出一个单句，就该拆 |
| MOC | 把同一主题的多篇聚成一个入口 | 攒够三篇再建，早建是负担 |
| 常青笔记 | 持续更新，随认知一起长 | 三个月没被打开，说明该删 |
| 卡片盒 | 用链接把孤立笔记连成网络 | 每篇至少连两篇，否则是孤岛 |

注意第七个「卡片盒」不是一种笔记，是**前六个的组织方式**。它不出现在某一环，它贯穿全程。

## 二、把它跑起来：两个完整走位

光看表格不会用。下面走两遍。

### 走位一：读一篇技术长文

假设你在读一篇关于检索增强生成的综述。

**① 捕获（闪念）**——读到一半突然想到「切分粒度太细会丢上下文，太粗会稀释语义」。这个念头十秒内丢进收件箱，不解释、不排版、不等想清楚。闪念笔记的价值在于**速度**，一旦开始整理，念头就凉了。

**① 捕获（文献）**——综述里关于分块策略的几段话值得留。摘录下来，**把原文链接一起存**。文献笔记里应该几乎全是别人的话，加一点点「这段在说啥」的批注就够。混进太多自己的观点，以后就分不清哪句是自己想的。

**② 精炼（永久 + 原子）**——把上面两份原料合起来，**用自己的话**写一篇《分块策略的权衡》。一个笔记只讲一个概念，所以它只谈分块，不谈嵌入、不谈重排。写完链接到另外两篇：一篇讲嵌入向量，一篇讲召回率。

这一步是全流程唯一真正产生知识的地方。前两步只是搬运，这一步才发生消化。判断标准很硬：**把原文关掉，这篇还看得懂吗？** 看不懂说明你在抄，不是在写。

**③ 存储**——放进它该在的领域目录。归位本身不产生价值，但放错位置的笔记等于不存在，因为以后找不到。

**④ 组织（MOC）**——当分块、嵌入、检索、重排、生成这几篇都攒起来了（三篇以上），建一个《检索增强生成专题》聚合页，把它们串起来。

**别提前建。** 只有一篇的时候建 MOC，是在给自己造一个空文件夹。

**⑤ 演进（常青）**——半年后做项目，发现长文档需要递归分块。回到《分块策略的权衡》，把新案例补进去。

这篇笔记从「一次写作」变成了「一个持续生长的判断」。这就是常青的意思——不是文笔好，是**它被反复修改过**。

**全程（卡片盒）**——上面每篇笔记里的链接，最终织成一张能走通的网。这张网的作用是：半年后你忘了当初怎么想的，但顺着链接能走回去。

### 走位二：读一份团队协作指南

换成非技术内容，流程完全一样，只是落点不同。

- **闪念**：「评审应该关注逻辑而不是格式」——一句话，丢进收件箱。
- **文献**：Google 的代码评审指南里关于「什么是必须拦下的问题」的那几段，摘录加链接。
- **永久 + 原子**：《代码评审的核心原则》，一篇只讲原则，链接到《反馈技巧》和《团队协作》。
- **组织**：评审、需求对齐、迭代协作这几篇攒够三篇后，建《团队能力》聚合页。
- **常青**：一次激烈的评审争执之后，回来给这篇补上「冲突怎么处理」。

## 三、四条不能破的约束

流程可以简化，但下面四条一破，整套就退化成文件夹整理术。

**第一，顺序不能跳。** 闪念 → 文献 → 永久，构成「捕获 → 消化 → 沉淀」的闭环。跳过闪念，你会在读到一半时开始写正式笔记，然后发现写不下去，因为还没读完。跳过永久笔记，你会有一堆摘录，然后以为自己学过。

**第二，领域不能混。** 技术内容、工程实践、思维方法，各有各的位置。混放的直接后果不是乱，是**同主题的东西散在三个地方，谁都不知道另外两处在哪**。

**第三，链接不能省。** 每篇永久笔记至少连两篇相关笔记。这条约束看起来繁琐，但它是唯一能让「卡片盒」真的成立的动作。写链接的时候你会被迫想「这跟什么有关」，而这个思考本身就是价值。

**第四，常青不能懒。** 高频引用的笔记要定期回访。不回访的后果是：你半年前的错误理解，会以权威笔记的形式一直躺在库里，被你自己反复引用。**没被修改过的笔记不是资产，是负债。**

## 四、最常见的失败方式

不是选错方法，是**在最贵的那一步偷懒**。

七个工位里，前两个便宜（十秒、几分钟），第四个之后才贵（组织、维护）。所以人的本能是从第三个开始就绕过——摘录完直接扔进文件夹，建个目录假装已经组织了。

半年后打开库，里面有三百篇文件，但你写不出一篇能直接用的文章。**因为三百篇里，没有一篇是你的话。**

补救的办法不是整理旧笔记，是**从现在开始，每收一份原料，必须当天写出一篇自己的话**。哪怕只有三行。三行的永久笔记，比三十篇摘录有用。
