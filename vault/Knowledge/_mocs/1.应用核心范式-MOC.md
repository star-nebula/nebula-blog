# AI 应用核心范式

## 概述

AI 应用开发的四大核心范式：RAG（检索增强生成）、Agent（智能体）、Function Call（函数调用）、LLM 应用产品化。理解这些范式是从「会用 API」到「能交付产品」的关键分水岭，也是 AI 应用开发岗位面试的核心考察点。

```
AI 应用/
├── Prompt 工程/   ← 提示词设计、思维链、Few-shot
├── NLP 任务/      ← 文本分类、情感分析、NER、翻译、摘要

```
