Cursor 删掉了自动记忆，这可能是三家 Agent 里最诚实的选择 ​

另外两家在拼命让 Agent 记得更准，Cursor 做了件相反的事：把自动记忆功能删了。

据官方论坛工作人员回复，chat Memories 自 2.1.x 起被有意移除。给出的理由很平淡：Memories 与 .mdc 规则差别不大，所以保留规则、删掉自动沉淀。

功能回退通常是负面信号。但仔细看它的替代方案，这次收缩其实有道理。

一、删掉的到底是什么 ​

chat Memories 原本的形态是：后台提取句子级事实，提议后经用户批准保存，项目级，仅本人可见。

这套设计和现在主流的"自动记忆"没有本质区别。它的价值在于"你聊得越多，它越懂你的偏好"。

它的风险也在这里：被提取的"事实"会过期。 半年前你说"这个项目用 Python"，今天已经换成 Go，但记忆还在。模型会带着过期前提给你提建议，而你不会察觉。

Cursor 的判断是：与其维护一个会过期的记忆，不如不要。

二、记忆被拆成两件事 ​

删掉自动沉淀后，Cursor 把"跨会话知道点什么"拆成两条独立的路：

稳定约定 → rules（人写，可评审，可进 git）

规则分几类：

  • 项目规则 .cursor/rules/*.mdc，进 git
  • User Rules，随账号同步
  • Team Rules，后台下发，可以强制
  • AGENTS.md（子树与父级合并，更具体的优先）

冲突时优先级是 Team Rules > Project Rules > User Rules。

触发方式由 alwaysApply、description、globs 决定：总是注入、按描述判断、匹配文件挂载、仅 @ 时生效。

历史信息 → 检索（本地索引，按需命中）

代码检索走 Instant Grep，在本机构建并查询索引。官方明确：不上传路径或代码建索引，也不存代码 embedding。

对话检索给历史 agent 转写建本地索引，并且已经作为 agent 可以主动调用的工具。

另有 Explore 子代理，在独立上下文里跑并行搜索，只回摘要。

三、为什么这是诚实的 ​

因为它承认了一件事：Agent 无法可靠判断"哪句话值得长期记住"。

Claude Code 信任模型判断，但给了一堆排除规则来兜。Codex 信任后台模型，用时间剪枝和额度门控来兜。Cursor 的选择是不赌：要记住的东西由人来定（rules），其余靠现场检索。

这三种态度没有绝对高下，但有明确差异：

  • Claude Code 的代价是索引会静默截断。
  • Codex 的代价是需要消耗额度，而且默认关闭。
  • Cursor 的代价是没有"越用越懂你"，每次都要靠规则和检索重建上下文。

Cursor 换来的是：不会因为一条过期记忆，被悄悄带偏。

四、被忽略的细节 ​

有几个设计容易被跳过，但能看出产品思路：

兼容 CLAUDE.md。 按 AGENTS.md 读取，且总是应用，忽略 alwaysApply。它在主动兼容别家的规则文件，降低迁移成本。

Projects 的共享上下文。 维护跨云/本地同步的上下文文件，各 agent 可以追加研究结论与操作知识。这算是一种"团队级记忆"，但仍然是文件形式，不是黑盒。

Automations 的 Memories 是隔离的。 每个 automation 有独立的记忆，默认 MEMORIES.md，存在工作文件系统之外，不与其他 automation 混用。

Agent SDK 的 memory hook。 每轮向 memory/journal.jsonl 追加一条 JSON，但模型没有 recall 工具。也就是说它只记录，不自动召回——把召回责任留给调用方。

最后这条尤其能说明态度：记录是自动的，召回是你的事。

五、什么情况下该学 Cursor ​

如果你的场景满足这两条，Cursor 的路线更省心：

  1. 约定是稳定的。 团队规范、技术栈、代码风格，这些变化慢，写进规则一劳永逸。
  2. 历史信息可以检索。 代码在本地、提交有记录，需要时搜一下比预先记着更准。

反过来，如果约定经常变、或者上下文散落在聊天里无法检索，那么自动记忆仍有价值——但你必须给它配一套淘汰机制，否则迟早被污染。

不确定性与边界 ​

  • "移除 Memories" 一条依据官方论坛工作人员回复与版本回退事实，官方文档已不再描述该功能。
  • 2.0.x 版本仍保留该功能，判断时需核对版本。
  • 第三方约定的 "Memory Bank" 是社区方案，不计入官方机制。
  • 本文以 2026-11-09 访问的官方文档与论坛回复为准。

总览见 三大编码 Agent 都没有记忆库，对照见 Codex 的记忆系统、Claude Code 的记忆系统。
